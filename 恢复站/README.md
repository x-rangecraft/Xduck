# 恢复站

本档案总结 XDuck 恢复站立策略在 2026-10-12 至 2026-10-13 的训练、回退、奖励修复和验证，截止模型 **3150**。整理日期：2026-10-14。来源是 Ubuntu5090 的实训配置、逐段完成记录、模型、审计 JSON 和实际轨迹视频。上传档案期间没有启动新训练。

目标一直是：**小扰动原地抗衡；支撑不足时主动迈步、协调全身避免倒地；确实救不住时倒地后自行站起；恢复后回到新默认站姿并安静下来。** 后期训练改善了最终站起和头部姿态，但没有保住早期的触地前恢复步。本档案同时记录成果和这个偏离。

## 先看模型链路

```text
v5 从零 0→300
  ├─ v5 300→600：升档后恶化，弃用
  └─ v6 300→2400
       ├─ v7 2400→2500→2600：修复后退化，弃用
       └─ 回到原2400，v8 2400→2800
            ├─ 2800柔性试训：用户停止，正式续训0轮
            └─ 刚性姿态修复 2800→2900→3000→3100
                 └─ 开柔性及柔性DR 3100→3150（50轮）
```

**3150是最终保留链路的累计 PPO 更新编号，不是所有试验的总计算量。** 另有数次独立从零试验、废弃分支和未完成的训练块，不能加到3150的父模型链里。这里“一轮”指一次 PPO learning iteration，不是一个完整8秒 episode。选中链路的轮数相加为 `300+2100+400+100+100+100+50=3150`。

## 必须统一的验证口径

此前“没有摔倒”“安静合格”“最后站起来”混用了不同标准。后续重审纠正了19个非足底接触传感器的geom映射。旧日志中的 `fell=false`、严格姿态门槛为0、旧成功率，都不能直接拿来证明身体没有触地或完全不会站立。

后期 **final_stand_v3** 判断最后0.2秒中至少80%帧满足：根部高度≥`0.319637239−0.03m`、身体倾角<20°、至少一脚支撑、结束时非足部离地。**此前任何时刻触地均允许**，默认关节角、线速度和角速度不作为这个终点成功的硬门槛。每次共112例：安静4、倾倒/初速20、推扰8、真实行走切站80。行走前缀本身摔倒的情况单列，终点统计仍按80次全部尝试，所以不应称为80次正常走路切换均不倒。

## 恢复步丢失的直接证据

将用户给的300视频对应条件固定：原引擎/机械模型、无DR、无观测噪声、+X 16N、每次0.4秒、相同的3次推扰数组。此处无DR只是定位回归的受控对照，日常验收仍使用DR。

| 同一视频协议 | 首次非足部触地前的确认恢复步 | 最大身体倾角 | 首次非足部触地 |
|---|---:|---:|---:|
| 主链300 | 2 | 47.28° | 1.40s |
| 主链400 | 1 | 50.81° | 1.40s |
| 3100 | 0 | 67.46° | 1.36s |

300右脚1.20s起、1.28s落、落点移4.4cm；左脚1.30s起、1.38s落、落点移3.0cm。两步都发生在首次身体触地之前，有腿部目标变化，不能当作单纯滑动。但300随后仍有头部触地，**它是保有恢复步探索的候选，不是已经完美不倒的成品**。也不能仅凭这些对照断言回归全部发生在某一次奖励修改；定位具体阶段仍需更多同协议中间模型测试。

3100在DR2.5、8方向、单次0.3秒的小推审计中：5/10N都8/8站住，无身体触地；15/20N都8/8最终站起，但各有2/8先身体触地，未确认触地前成功恢复步。冻结推前目标的对照15/20N仅6/8最终站起，说明策略仍有主动自救，主要发生在触地后。3150的常规20个倾倒样本全部中途身体触地，8个推扰有7个触地；终点100%绝不代表全程不倒。

证据：[相同视频条件审计](runs/stand_3000_head2deg_adapt100_20261013/early300_review/SAME_VIDEO_CONDITIONS_COMPARISON.json)、[小推审计](runs/stand_3000_head2deg_adapt100_20261013/small_push_audit/COMPACT_REPORT.json)、[原300/400视频](videos/300_vs400_original.mp4)、[3100推扰与固定目标对照](videos/3100_15N_policy_vs_hold.mp4)。

## 后续重训应继承哪些经验

优先评估早期300等仍有恢复步的候选，避免直接以3150为唯一续训起点。新的学习目标要把“无身体触地恢复”设为更优，把“倒地自起”保留为后备。先建立同协议的恢复步、原地抗衡、地面自起三组基准，再改奖励与采样；不能再靠合并终点成功率一个数字升档。

较大探索应保留，但用有界增量动作控制真实关节变化。恢复过程中释放站姿约束，恢复安全状态后才强调高度、直立、头部/腿部姿态和静止。每个阶段持续重采样小/中扰动、走停和早期会迈步的任务；困难倾倒/大推不能挤掉这些任务。状态门控只控制当前奖励，**不会保护共享神经网络权重不遗忘旧动作**。用奖励、任务重采样及回归验收保持技能，不加入动作轨迹教师。

进一步的奖励和课程建议见 [训练经验与下一版设计](docs/经验与下一版.md)。这些是后续建议，尚未训练或验证，不应当成已完成修改。
