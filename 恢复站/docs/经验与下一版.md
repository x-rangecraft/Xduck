# 从这3150轮保留下来的经验与下一版方向

这是待实施建议，档案上传不代表已开新训练。

## 下次目标排序

1. 在可以原地抗衡的小推下不触地、恢复后静止。
2. 需要改变支撑时允许移动、抬脚、重落点、全身协调，优先在身体触地前救回。
3. 超出当时可恢复范围时允许倒地，并保持自主站起能力。
4. 最后回到有合理容差的新默认站姿，头部两轴误差及安静单独统计。

奖励不能让2和3在同一终点得分上完全等价，也不能把所有触地轨迹直接截断。前者容易学成倒下再起；后者会切断已学会的后备能力。更大的惩罚也不能凭空增加有效恢复探索样本。

## 起点选择及课程顺序

先用统一协议比较300及其他较早候选，再选择仍有救回动作的起点；300已有两次触地前迈步证据，但也会触地，所以不能直接宣布它达标。2800/3100/3150适合保留为自主站起和姿态对照，不能因终点100%自动选为最好的防倒初始化。

保留较大的可学习探索以及有界物理增量。先在足够多、仍有机会救回的中等推扰/动态初态中探索重落脚和全身调整；同时混合无推扰和小推，以学会最终静止，而不是只探索长期躁动。逐渐增加力、时间、方向、倾角及DR，每档都保留已会的旧任务。

不要让60%长时间大推和极端初态把早期会迈步的中等任务挤掉。可分别维护原地抗衡、中等可迈步恢复、行走切站、困难倒地自起样本池。确切采样比例、奖励系数和升档条件应在短对照试验中确定，本档案没有声称已找到最优值。

## 奖励修改原则

- 高度、身体直立、合理腿部结构持续说明“最终要站起来”，不再容许低头低身高撇腿成为高分静态解。
- 恢复过程中不给移动/角速度/离地动作过强的安静惩罚；安全状态稳定一段时间后，才奖励静止和默认姿态。
- 对身体触地风险、实际触地持续时间、恢复耗时设置合理代价，让能站着救回的方案比先倒地再起更优，同时保留触地后继续探索及终点站起收益。
- 脚步是允许的手段，不强迫每次推扰都抬脚，也不要求固定轨迹或指定腿先迈。小推原地抗衡成功应同样获高分。
- 审计任何可由自身运动触发的门控，防止主动进入危险状态规避姿态/速度成本。
- 每次只改少量有明确解释的因素，避免再次同时改动作范围、GAE、终止、奖励和采样而难以定位回归。

这里“倾角区分静止与恢复”应结合高度、支撑、线/角速度，而不是单独用倾角；身体尚直立但有很大动量也需要提前救回。

## 验证和保留标准

每100轮保存并验证，分别报告：原地不触地成功率；触地前主动脚步及其后成功率；实际身体触地率；触地后最终站起率；走停交接；安静及头部/腿部姿态。报告分组分母，不能用80个走停掩盖8个推扰的失败。

脚步证据要包含离地、腾空时间、落点变化、主动关节目标变化及首次身体触地时刻。足底滑动、原地震颤、倒地后的甩腿不算触地前恢复步。保留真实逐帧轨迹和接触重审，不凭视频文字或旧传感器标志判断。

常规验收保留用户要求的DR；定位某阶段退化时使用同一机械参数、方向、时长和噪声的受控对照。300原视频协议应加入长期回归集。升档仍可遵循用户总体90%意愿，但需同时展示关键分组退化，避免终点达标掩盖防倒能力下降。

## 工程经验

4096环境、20步、刚性1ms是已确认的效率基线；100轮检查一次。柔性要等刚性行为目标达标再适配，并实测其DR确实写入被动关节刚度和阻尼。终点奖励要正确处理timeout和potential。动作解码、关节顺序、归一化、切换时上一目标和延迟历史要保持契约。

不要将历史旧Warp源码直接覆盖当前simulation分支的新框架；恢复旧环境或做迁移时先检查动作/观测/机械/传感器契约。此处不引入动作教师、不做轨迹模仿，也没有启动任何新的训练。
