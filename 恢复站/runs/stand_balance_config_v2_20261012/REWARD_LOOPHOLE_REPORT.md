# 奖励漏洞专项检查（训练暂停）

本次只做评分单元反例和已保存数据分析，0次PPO更新。不是完整物理轨迹的回报优化，也不是受控重训消融。结果见REWARD_LOOPHOLE_AUDIT.json。

## 确认的评分反例

固定身体直立、名义高度、零水平速度、同一关节误差、相同动作差及关节速度，仅改变俯仰角速度。每轴动作差取1个0.12rad单位、关节速度3rad/s：

| 俯仰角速度 | 原始总评分（乘20ms前） |
|---|---|
| 0.8rad/s | 7.88854 |
| 1.1rad/s | 8.05500 |

更快的倾倒速度触发预测恢复，降低动作/关节运动成本，节省的成本超过额外角速度的损失，导致分数反而上升。这是奖励函数排序的反例，不能说明任意完整物理过程都能这样获利。

保持同一身体与运动数值，仅替换脚接触标记：双脚9.668、单脚9.80765、无脚接触10.067。支撑越差，恢复权重越高，运动成本更低。脚接触不是可独立任意设置的物理变量，因此此测试揭示门控结构的风险，不是离地动作的实测净收益。需要额外检查真实起落脚轨迹的完整回报。

已保存真实300轮回放支持这条机制确实经常生效：无推、确定性均值平均恢复权重54.5%；同轨迹关节速度成本比安静强度低16.5倍。训练采样回放恢复权重98.3%，低19.2倍。

## 没有证实的进展刷分

当前进展项为2*(up_next-up_prev)。上方向势值0.99→1.0→0.99，未折扣的完整周期净奖励为0，不能说抬回一次只奖不罚。gamma0.99时，该低→高→低周期的折扣和为0.0002，存在时间排序差异，但不足以证明反复摇摆优于恢复后保持竖直。

若需要严格的潜势塑形，应与PPO折扣一致，采用weight*(gamma*Phi(next)-Phi(current))，并处理真实终止的终态势值、回合重置和超时bootstrap。不能仅截断正向进展或每次重新进入恢复模式都给奖金。理论来源：https://people.eecs.berkeley.edu/~russell/papers/icml99-shaping.pdf 。本检查没有修改进展代码。

## 调整原则（待配置）

1. 基础动作变化、关节/身体速度成本保持轻量且常开，不能因策略自己晃动、预测倾角变大或少一只脚着地而整体降低。
2. 静止和恢复的区别主要体现在姿态约束的容许范围、实际恢复进展和最终收敛目标；恢复动作需要付出运动成本，但成功救回和停稳应有更高收益。
3. 若给予恢复完成奖励，仅由独立外推事件或初始化的失衡状态激活，每个事件只领取一次，策略自行制造失衡不能重新激活。
4. 外推→恢复→无推静置构成完整回合，包含多次外推与无推保持样本；判断总回报而不是只看某一步。单脚支撑允许恢复步，但本身不给奖励，失去支撑也不减少基础费用。
5. 探索不等同于全时段14轴强随机抖动；早期包含轻扰动和可恢复初始状态，把探索集中于恢复发现，收尾收敛。改变采样噪声必须保持PPO动作概率一致。
6. 用真实轨迹和评分反例同时检查：静止、主动自扰动、有效恢复步、无效踏步、离地摆动、恢复后持续躁动、反复进入恢复模式、倒下提前结束，防止仅修补一个反例。

结论：确认奖励门控存在降低运动成本的结构漏洞；同时存在探索噪声增长和学习分布问题。尚不能将全部躁动归因于某一个项，也不能宣称上述修正已验证有效。训练仍暂停，当前配置没有自动改动或启动。
