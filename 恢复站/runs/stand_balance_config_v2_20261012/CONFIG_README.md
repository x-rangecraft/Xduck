# 静止／站停／恢复配置 v2（新奖励从零训练）

实际配置：TRAINING_CONFIG.yaml，生效奖励组为 `env.balance_reward`。继承的旧 `reward` 组保留用于基础环境配置兼容，新的站立奖励由 `scratch_balance.py::_compute_reward` 和 `balance_reward.py` 计算，不能以旧组权重判断本版行为。

## 三种行为连续加权

- 安静站立：倾角小、运动小、高度接近站立、双脚支撑。加强姿态、动作变化和关节速度约束。
- 站停／收尾：身体可能直立，但仍带水平/上下速度、旋转或关节运动。持续减速、收步，避免把起立末段误认为静止。
- 失衡恢复：明显倾斜、预判倾倒、低身体高度或支撑不足。放宽动作变化和默认姿态约束，允许全身协调与恢复步。

倾角使用实际身体上方向；当前倾角与按角速度预测0.2秒后的倾角取较大值。6°以下充分支持安静收敛，12°以上充分支持恢复，区间内smoothstep过渡。原地yaw旋转不误判为倾倒，但仍需要减速。高度门控从参考高度80%到95%平滑过渡。单脚支撑不给安静站立权重，仍保留站停/恢复权重。三个权重相加为1；不是推理时硬切三套动作。

上述阈值是本版拟定配置，不是已通过抗倒验证的界限。门控用于训练奖励；actor仍61维，不新增速度、接触或模式输入。训练中使用仿真提供的速度和接触信息塑造反馈行为，不能宣称61维网络已经具备任意状态识别能力。

不再用速度门控关闭零速度目标；不再仅靠4cos(tilt)和很窄的停稳奖金教静止。抬脚或迈步不按次数给奖励，也不硬锁脚。恢复过程中保持最小姿态回归，并降低平滑成本，稳定后再收敛。

## 通用状态与课程

沿用六级外力课程（最大约0/3.5/7/13/22/31N，机身/头部、各方向短推和持续推），以及每100次更新后的独立验收门槛。没有达标不提高外力。输入61维、柔性和柔性DR关闭、机械1ms、控制20ms。源物理模型、质量惯量、GF43X40执行器/增益/通信及足底安装±3°保持。

通用初始状态包含倾斜、水平/角速度、不同支撑和从第2级起的屈腿低高度状态，加入上下速度[-0.15,+0.20]m/s与关节运动。低高度初始状态至少为名义高度65%，保留与失败阈值的余量。具体几何落地结果见STATE_COVERAGE.json，初始状态在冷路径生成，训练热路径只采样缓存。

用户提供的xduck_sitstand_2000_export.zip只保留为参考，不执行该策略、不新增起立策略阶段；通用物理状态用于覆盖接管时的姿态与运动。该资料包实际是61维Identity actor和tanh增量积分目标，并不是之前发现的62维model267策略；没有将两者混用。
