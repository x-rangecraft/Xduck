# Xduck 坐下／起立：2500 轮训练归档

归档日期：2026-10-12。本目录保存实际使用的旧版训练链路、2000→2500 轮续训配置与证据，以及已导出的 2500 轮策略。它是独立归档，不使用相邻 `walk/stand/xl330` 的新版 UniLab 1.3.1 入口。**模型已导出，但坐站稳定成功率仍未达到工程目标，头部大幅运动也未解决。**

## 训练过程与选择

主线来自随机初始化普通 MLP＋PPO。最终选择的是“原 1250 参数不变续训到 1500”的 `unchanged_resume`，没有选择另一个修改奖励的 1500 模型；随后完成以下续训：

|阶段|更新次数|变化|
|---|---:|---|
|1250→1500|250|沿用原 1250 主线参数|
|1500→1750|250|现有 DR 偏差范围扩大为 1.5 倍|
|1750→2000|250|现有 DR 偏差范围扩大为 2 倍|
|2000→2500|500|改为用户的新默认站姿，保留 2000 的 PPO、奖励、动作映射、GF 和 2 倍 DR|

这里“2 倍 DR”指配置中的偏差范围扩大，`env.dr_level` 仍为 1.0，不是设置为 2。本归档保留 1500 原始配置、两个 DR 阶段配置以及 2000→2500 原始启动配置。提供 2000 起点权重，可重跑最后 500 轮；不宣称完整复现此前每个试验分支或逐位复现训练曲线。模拟器与随机数全部运行状态没有随 checkpoint 保存。

此次 500 轮每轮 4096 环境×24 步，即 98,304 样本，合计 49,152,000 样本。完成时累计环境步计数为每环境 60,000；累计更新数 2500。单个训练种子为 1。没有新增训练。

## 模型、控制和 PPO

Xduck 1.1.2 刚性模型，GF43X40 标定执行器；没有把 GF 改成 XL330。仿真步长 1 ms，控制步长 20 ms，GF 在物理子步计算。actor 观测 61 维，critic 76 维，14 个动作；MLP 为 512/256/128，ELU。actor 不做观测归一化，critic 做归一化；初始标准差 0.25、初始均值输出增益 0.01。续训加载策略、critic、优化器和进度。

PPO：学习率 0.0003，fixed schedule，entropy 0.005，5 epochs，8 minibatches，clip 0.2，gamma 0.997，lambda 0.99，梯度裁剪 1；每 25 轮保存。详细参数以原始运行配置为准。

动作是**关节目标增量**：

```
target_next = clip(target_previous + increment * tanh(raw_action), target_low, target_high)
```

策略顺序为左腿 5、头部 4、右腿 5。每控制步最大增量（rad）：
`[.015,.010,.080,.060,.075,.110,.025,.025,.010,.015,.010,.080,.060,.075]`。
观测中的 14 维历史项是 `(previous_target-default)/0.12`，不是上一帧原始动作。启动时用实测关节角初始化累计目标，坐站命令切换时保留累计目标。不能把 ONNX 输出直接作为位置指令，也不能每帧把累计目标复位；具体排列、绝对目标边界和命令定义见 `policy_io.json`。

最终主线头部仍使用原增量映射，没有采用后续实验的头部绝对映射或 ±30° 限制。机械硬限位和 GF 标定参数保持不变。

## 新站姿

策略顺序、单位 rad：

```
[0, .08, .394, -.061, -.455, .019, .06, 0, 0,
 0, -.08, -.394, .061, .455]
```

坐下的初始站姿与起立目标站姿共同使用 `STAND`，由任务片段 `stand_user_20261012.xml` 定义；站姿高度奖励目标为 0.3198 m，站姿初始化高度为 0.3217271866 m。reset 仍有 0.1 rad 关节噪声，因此视频第一帧不是逐角度完全等于名义站姿。

坐姿腿部目标未变：左 `[0,0,.625,-1.14,-.35]`，右 `[0,0,-.625,1.14,.35]`；高度目标 0.2182 m，初始化高度 0.22 m。新站姿同时改变默认角度基准、相对关节观测和头部命令基准，2000 权重需继续适应这些变化。限幅偏移重新表达以保留原有绝对目标边界。

冻结物理模型只替换 STAND 的 qpos/ctrl，质量、惯量、阻尼、armature、摩擦、关节范围、几何、执行器参数、重力和步长均核对不变。名义站姿固定控制验证为 16 环境、5 秒、0 跌倒，末段高度 0.319776 m、身体倾斜 0.216°、头部倾斜 2.185°；这证明静态可保持，不能替代学习策略验收。

## 奖励、课程与 DR

本次没有加入参考轨迹、模仿动作或手工运动分支，也没有改成反向课程。保留主线坐站奖励及修复开关：高度、姿态/复合目标、身体直立、头部命令跟踪、静止、动作变化、运动、限位、接触和目标溢出等；错误高度正向项 gate 开启，discovery_motion_cost_multiplier=0.1。完整系数在 `configs/run_config_original.json`，实际分支与公式在 `unilab/src/unilab/envs/locomotion/xduck_gf43x40/`。课程会覆盖部分静态 reward.scales，不能只读取该字典判定最终有效惩罚。

坐站命令驻留 3.5～6.5 秒，目标姿态 slew 2 秒，站/坐 reset 各约一半。头部随机命令每 2.9～7.2 秒重采样，范围在每环境步 0、12000、24000、36000、48000 逐步加大；最终四轴范围为 ±1.1、±1.1、±1.4、±0.31 rad，再与关节可用范围相交。固定零头部命令只用于评估，没有据此改变训练分布。

2 倍 DR 的主要实际范围：足部摩擦 0.4～1.6；躯干质量/惯量倍率 0.9～1.1（非全身）；armature 0.8～1.2；IMU 安装角最大 12°；观测噪声 level=2。躯干 COM 扰动课程最大 ±0.0627 m，头部 ±0.0418 m。平面速度 push 每 3～6 秒，48000 步上限 0.5782 m/s，60000 步增至 0.8674 m/s；60000 步起立速度惩罚课程也加大，所以最终评估采用的是这一阶段。

电机 DR 开关、kp/kd 随机化、关节摩擦随机化关闭；任务 reset 中执行器 friction_scale 仍采样 0.9～1.1，不能据电机 DR 开关推断所有执行器量完全固定。执行器延迟 0，IMU 延迟 0～20 ms，关节速度延迟 20 ms；这些延迟和初态噪声没有乘 DR 倍率。

每类动作 2 个环境种子（6401、7401）×16 环境=32 次；6 秒 rollout，策略确定性均值输出，保留原 DR/噪声，在 checkpoint 进度冻结课程。

## 导出接口修正及验证

此前最初的 2000 导出包错误地用冻结模型 HOME 作为默认关节基准，而训练实际使用 STAND；已发布修正版。本次 2500 的默认角度与边界从实际任务环境提取，并核对新站姿。它影响相对角度观测、目标历史和解码，不能据此认定所有真机问题均已解决。

ONNX 固定 float32 输入 `[1,61]`、输出 `[1,14]`，opset17。原导出验证使用 1024 个物理观测＋65 个检查观测：最大原始动作差 2.38419e-6，解码位置差 7.86781e-8 rad，参考解码与任务解码差 0；关节重排往返、零动作保持目标、默认站姿和 GF 校验也通过。见 `evidence/export_validation.json`。这是数值一致性验证，不是动作成功验证。

## 使用归档

Linux NVIDIA CUDA 12.8、Python 3.10；训练实际使用 Torch 2.7.0+cu128、MuJoCo 3.10.0、MuJoCo-Warp 3.10.0.3、Warp 1.14.0、UniRL 1.3.0、RSL-RL 5.0.1。全部实装版本见 `evidence/environment_versions.json`。冻结 MJB 依赖匹配的 MuJoCo 版本；不要用新版其他工程运行它来推断策略效果。

```bash
cd sitstand
uv venv --python 3.10 .venv
uv pip install --python .venv/bin/python -r requirements-runtime.txt
# requirements 给出核心依赖；全部实装版本是证据清单，不是跨平台锁文件。
export XDUCK_PYTHON="$PWD/.venv/bin/python"
./run.sh verify   # 校验默认角/边界、加载 checkpoint/ONNX、执行物理步
./run.sh eval     # 重评2500并生成几何验收，写入 outputs/
./run.sh train    # 从2000起点重跑500轮，写入 outputs/；不是从2500继续
```

`run.sh` 自动设置工作目录与 PYTHONPATH，使归档 runtime_snapshot 优先，不改相邻工程。可移植配置只重写文件/输出路径；原始服务器配置和启动证据保留。本次归档验证使用服务器现有匹配运行环境；没有宣称全新机器依赖安装已验收。

源码许可证分别见 `unilab/LICENSE` 和 `runtime_snapshot/*LICENSE.txt`。运行快照保留原路径作为溯源证据；不包含原始真机返回日志、账号凭据或环境虚拟目录。

归档独立路径验证：16 环境执行 16 个控制步、默认角与边界一致、物理观测有限，ONNX 最大动作差 4.76837e-7；见 `evidence/archive_validation.json`。该报告的 env_steps_per_env=60016 包含验证新增的 16 步，checkpoint 训练计数为 60000；验证未做 PPO 更新。
